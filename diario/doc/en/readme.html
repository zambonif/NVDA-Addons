Diary for NVDA

Version 1.4.1

Diary for NVDA is an accessible, offline personal diary integrated with the screen reader. Its distinguishing combination is dated entries and automatic creation timestamps inside a password-protected encrypted vault, with optional recovery and an accessible real-time spell checker.

What's new in version 1.4.1

  • The spell-checking language can now be selected separately. By default, it follows the interface language; System default uses the language configured in Windows, including Romanian or any other language provided by the installed Windows Spell Checking API.
  • Spelling-warning sounds can be disabled without disabling suggestions, the accessible context menu or the personal dictionary.
  • Preferences saved by previous versions remain compatible.

What's new in version 1.4.0

  • Security hardening following the received report: the PBKDF2 algorithm, iteration count, key length and derivation purpose are now authenticated with the internal key by AES-GCM. The accepted minimum is 600,000 iterations.
  • Compatibility with older vaults: when an older vault is unlocked, the protection that was used is upgraded automatically. Recovery-phrase protection is upgraded when the phrase is used or changed.
  • Import and export of the personal dictionary as UTF-8 TXT, with validation and merging that preserves existing words.

Opening the Diary

  • From the NVDA menu, choose Tools, then Diary.
  • Or press NVDA+Alt+D. The command can be changed in Input Gestures, under the Diary category.

The add-on requests the password before showing any entries. Lock and close, or closing the window, removes the key from the session, so the password is required again next time.

Using the Diary

The main window lists entries from the newest selected date to the oldest. Each entry has a title, text, a user-selected date and an automatically recorded creation date and time.

  • New entry: opens title, day, month, year and entry text fields.
  • Read: opens the selected entry in a read-only text box. Enter on an entry also opens it.
  • Edit: changes the title, selected date and text without losing the original creation timestamp.
  • Delete: requests confirmation before removal.
  • Export backup: saves both encrypted vault copies in a ZIP.
  • Import backup: adds only entries that do not yet exist in the open Diary.
  • Change password: confirms the current password and sets a new one.
  • Recovery phrase: sets, replaces or removes the phrase after confirming the password.

Real-time spell checking

The title and entry text are checked while typing. After a word is followed by a space, punctuation, Tab or Enter, a warning sound is played if the Windows dictionary considers it misspelled. The typed delimiter is always inserted, so you can ignore the warning and continue.

Place the caret on or after the word and press Applications, Shift+F10 or Alt+F10. You can also right-click the word. The accessible menu provides up to eight suggestions, selectable with the arrow keys and Enter, followed by:

  • Ignore for this session: suppresses further warnings for the word until NVDA is restarted.
  • Add to local dictionary: saves the word in dicionario.txt and suppresses future warnings.

The feature uses the native Windows Spell Checking API and the language selected for the Diary. If Windows has no dictionary for that language, only spell checking is unavailable; creating, reading and saving entries continues to work normally.

dicionario.txt is a UTF-8 file containing only words explicitly added by the user. It is not encrypted because it contains no diary entries, and it is shared by all five interface languages.

The Export dictionary and Import dictionary buttons save a TXT copy and merge words from another installation. Import validates the file, preserves existing words and adds only new ones.

Encrypted backup export and import

These two commands are available only after the Diary is unlocked. Export backup opens a Save dialog and creates a ZIP containing exactly diario.enc and diario.backup.enc. Both files remain encrypted; no entry data is written in plaintext.

Import backup validates both encrypted files in a temporary location, compares entry identifiers and saves only missing entries into the current vault. Existing entries are never replaced. Dates, titles, text and creation timestamps are preserved.

A backup from the same vault needs no additional password. An independently created vault has a different random key, even if its password text is the same, so the add-on requests that backup's password. It does not change the current Diary password. An invalid ZIP, incorrect password, cancellation or a backup with no new entries leaves the current Diary unchanged.

Keyboard commands

  • NVDA+Alt+D: open the Diary.
  • Ctrl+N: new entry.
  • Enter: read the selected entry.
  • Ctrl+E or F2: edit.
  • Delete: delete.
  • Escape: close or cancel.
  • Applications, Shift+F10, Alt+F10 or right-click: suggestions for a misspelled word.

Interface language

Open NVDA menu, Preferences, Settings, Diary. Choose Brazilian Portuguese, Spanish, Italian, French or English without changing NVDA's general language. The spell-checking language can follow the system default, match the interface or be selected independently. Spelling-warning sounds can also be disabled without disabling the checker. New windows use the interface choice immediately. Restart NVDA to update the Tools menu item, settings category and input-gesture description as well.

Storage, security and privacy

Data remains on the computer, below the NVDA configuration directory in the diario folder. The main vault is diario.enc; its encrypted backup is diario.backup.enc. The add-on does not send entries to the internet.

All entry content, including titles and dates, uses authenticated AES-256-GCM encryption through Windows CNG. The random vault key is protected from the password with PBKDF2-HMAC-SHA256 using 600,000 iterations. If configured, the recovery phrase protects the same key separately.

Version 1.4.0 also authenticates the algorithm, iteration count and all other derivation metadata when protecting the internal key. Changing those parameters makes cryptographic verification fail. When an older vault is opened, the wrapper used to unlock it is upgraded automatically.

The phrase does not reveal the old password; it permits the user to create a new one. If both password and phrase are forgotten, the add-on cannot recover the entries. Use long, hard-to-guess secrets and keep independent backups of the encrypted files.

Version 1.4.0 keeps the vault format compatible with version 1.1.0.
